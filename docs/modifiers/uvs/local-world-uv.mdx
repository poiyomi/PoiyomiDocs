This section houses the settings for the Local World UVs to use for certain UV modifiers. To use it, select it as a UV option in supported sections of the shader.

## Local X

<Property type="dropdown" options={['X', 'Y', 'Z', 'Zero', 'VColor R', 'VColor G', 'VColor B', 'VColor A']} default="X" />

Sets the Local X-axis of the UV.

## Local Y

<Property type="dropdown" options={['X', 'Y', 'Z', 'Zero', 'VColor R', 'VColor G', 'VColor B', 'VColor A']} default="Y" />

Sets the Local Y-axis of the UV.

## World X

<Property type="dropdown" options={['X', 'Y', 'Z', 'Zero']} default="X" />

Sets the World X-axis of the UV.

## World Y

<Property type="dropdown" options={['X', 'Y', 'Z', 'Zero']} default="Z" />

Sets the World Y-axis of the UV.
