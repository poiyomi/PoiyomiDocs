Voronoi is an effect that generates a noise pattern across the Material, either in 2D or 3D, making for very interesting stylized effects.

## Type

<Property type="dropdown" options={['2D', '3D']} default="3D" />

Choice of Voronoi effect to use. Each of these are self-explanatory due to the way they function.

## Space

<Property type="dropdown" options={['Local', 'World', 'UV']} />

Where should the Voronoi effects be simulated on.

## UV

<Property type="dropdown" options={['UV0', 'UV1', 'UV2', 'UV3', 'Panosphere', 'World Pos', 'Local Pos', 'Polar UV', 'Distorted UV', 'Matcap', 'Screen Space']}>
Space is set to `UV`
</Property>

Selection of UV to use for the Voronoi.

## Blend

<Property type="dropdown" options={['Color and Emission', 'Just Emission']} default="Color and Emission" />

Chooses how you want the Voronoi to Blend with the Material.

## Affects Material Alpha

<Property type="toggle" />

If enabled, the Voronoi will also affect the Material's Alpha.

## Colors

### Outer Color

<Property type="color" />

Choice of Color to use for the Outer Voronoi.

### Outer Emission

<Property type="range" min="0" max="20" />

How much Emission to add to the Outer Voronoi's color.

### Inner Color

<Property type="color" />

Choice of Color to use for the Inner Voronoi.

### Inner Emission

<Property type="range" min="0" max="20" />

How much Emission to add to the Inner Voronoi's color.

### Hue Shift

<Property type="toggle" />

Enables Hue Shift on the Voronoi.

#### Color Space

<Property type="dropdown" options={['OKLab', 'HSV']} default="OKLab" />

Choice of Color Space to use for the Hue Shift. By default, it will be set to `OKLab`.

Learn about the difference of Color Spaces as documented here in [Color Adjust](/color-and-normals/color-adjust.mdx#oklab-vs-hsv).

#### Hue Shift Speed

<Property type="float" />

How much to constantly shift the Voronoi Hue with time. A value of 1 will result in a full hue shift cycle every 20 seconds.

#### Hue Shift

<Property type="range" min="0" max="1" default="0" />

How much to shift the Voronoi around the hue circle.

This value is circular, and will have the same result at `0` and `1`.

## Voronoi Random Cell Color

<Property type="toggle" />

Enables the ability to apply random saturation and brightness to each Voronoi cell simulated.

### Saturation Range

<Property type="clamped" min="0" max="1" />

Minimum and Maximum range of Saturation to apply to each randomized Voronoi Cell.

### Brightness Range

<Property type="clamped" min="0" max="1" />

Minimum and Maximum range of Brightness to apply to each randomized Voronoi Cell.

## Shape & Motion

### Scale

<Property type="float" />

How large or small to scale the Voronoi effects.

### Power

<Property type="float" />

How much power to add to the Voronoi.

### Gradient

<Property type="vector2" />

In X and Y coordinates, determines the Gradient location of the Voronoi in the 2D space.

### Speed

<Property type="float3" />

How fast to move the Voronoi effect among the simulated space.

### Cell Motion

<Property type="range" min="0" max="1" />

The amount of motion applied to the cells on a scale of 0 to 1.

### Cell Motion Speed

<Property type="float" />

Sets how fast the cell motion is simulated.

## Noise

### Noise

<Property type="texture" texture="data" />

Which Noise Map to use for the Voronoi effect.

### Noise Intensity

<Property type="range" min="0" max="1" />

How much intensity to add to the Noise Map, if provided.

## Masking

### Mask

<Property type="texture" texture="data" />

Determines where to contain the Voronoi effects and where it should only appear in.

### Global Mask

<Property type="dropdown" options={['1R', '1G', '1B', '1A', '2R', '2G', '2B', '2A', '3R', '3G', '3B', '3A', '4R', '4G', '4B', '4A']} />

Same as above, but uses a [Global Mask](/modifiers/global-masks.mdx) instead to determine the Mask.
