This update contains some minor bug fixes and improvements. The Toon version is now available in the VCC Repository, GitHub, and on BOOTH.

### Changes
- Changed default `VR Parallax Strength` value in Matcaps to `1`. If this was `0`, it would be flat in VR.
- Apply & Rebuild on User Modules now stop reporting installed modules as duplicates of themselves.

### ThryEditor 2.74.4
- Backport: Stop the VRC SDK from clearing our VRC Fallback Tags.
