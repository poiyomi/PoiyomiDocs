This update fixes a bug with the Modular Shaders Generator where the output files would go to the wrong folder instead of the root installation path of Poiyomi Shaders by default. This was particularly important for VCC installations. I also slipped in a few fixes to some typos and UI mistakes I noticed in between.

The Toon version is now available in the VCC Repository, GitHub, and on BOOTH.

### Changes & Fixes
- Fixed an issue where default Shader Destinations would point to the wrong folder by default on VCC installs.
- Fixed a bug where `Light Direction Mask` was completely missing from the UI in Rim Lighting 1's UTS2 Mode.
- Some typos and capitalization issues fixed.
