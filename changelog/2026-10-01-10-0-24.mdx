This update contains bug fixes and is recommended for all users. The Toon version is now available in the VCC Repository, GitHub, and on BOOTH.

## Changes & Fixes
- Repaired Dissolve Translations. Translating Dissolve from 9.3 to 10.0 will now force the following:
  - `Edge Line` ON since 9.3 always had Edge enabled regardless.
  - `Gradient Noise` ON when a Dissolve Noise texture is detected.
- Fixed potential NaN errors encountered in Lil Fur.
- View Clip Prevention (Uzumore) scaling calculation now has **manual scaling** that multiplies the Push Bias and Push Amount values. This added the Float property `Object Scale` to the module, set to `1` at default.
  - *We added this property in order to allow users to have more control over the Uzumore effect's behavior. I urge you to carefully read the updated [Documentation page](https://www.poiyomi.com/vertex-options/view-clip-prevention#object-scale) on how to properly use it.*
- View Clip Prevention (Uzumore) now intentionally skips the Shadow Pass to fix various issues.
