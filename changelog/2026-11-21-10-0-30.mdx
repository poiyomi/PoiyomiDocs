This update contains some minor bug fixes and improvements. The Toon version is now available in the VCC Repository, GitHub, and on BOOTH.

:::note
10.0 LTS is now feature-locked. Updates will be bi-weekly unless a critical issue arises that requires immediate attention.
:::

### Changes & Fixes
- Fixed a bug where `SP_ParticleOutsideOnly` was causing the Presets system to throw a hissy-fit.
- Fixed an issue where resolving template source includes as project paths had terrible behavior on symlinked paths.
- Anisotropic GGX is now finite when half vector points into surfaces.
- Improved the generation speed of the Modular Shader Generator.
