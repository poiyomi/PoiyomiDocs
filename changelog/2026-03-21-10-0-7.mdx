You can download this version from [pro.poiyomi.com](https://pro.poiyomi.com) by logging in via your Patreon account. Alternatively, use the Poiyomi Pro VCC package by following the instructions [here](/download#pro-version-method-1-vcc-package).

### Changes
- Change viewDir back to per-eye.
- Fix networked time, set default back to vrc network time.
- Replace `multi_compile` fog with `dynamic_branch` to halve fog variants
- Add `PoiDynamicBranchVariantStripper` for Unity 2022.3.0-39 to strip redundant variants caused by the `dynamic_branch` bug (based on Error-mdl's Unity2022-Dynamic-Variant-Fix).
- Fix RNG function in Constellation.
- Fix RimLight masking.
