You can download this version from [pro.poiyomi.com](https://pro.poiyomi.com) by logging in via your Patreon account. Alternatively, use the Poiyomi Pro VCC package by following the instructions [here](/download#pro-version-method-1-vcc-package).

### Changes
- **Added Light Volumes 3.0**
- Lava Lamp new docs
- Lava Lamp global themes
- Fixed Matcap 3 locking
- Fixed Triplanar Depth using the add pass
- Added video effects to decals
- Expose AudioLink debug options
- Fixed panosphere, added panosphere override option
- Added Proximity Color alpha and emission override option
- Added back White channel to Metallics and Specular
- Fixed spelling errors

### ThryEditor 2.71.2
- Shader Translator: Skip locked shaders
- Added Material Upgrade Hook for upgrading materials
- Added warning when Unity's String Comparison bug is detected
- Fixed Global Linker sometimes not updating properties of linked materials
- Added AL Spectrum to shader upgrade
- Cleanup presets on apply
- Fixed material properties clipboard between versions
- Fixed UV Tile label display
