The Cubemap section is similar to the Matcap section, but allows you to use a [cubemap](https://docs.unity3d.com/Manual/class-Cubemap.html) texture instead of a matcap texture. Cubemaps can be used to simulate reflections and other effects, and avoid some of the projection artifacts that occur with matcaps.

## UV Mode

<Property type="dropdown" options={['Skybox', 'Reflection']} />

Determines which projection mode should be used for the cubemap UV.

### Skybox

Skybox maps the cubemap based on the view direction. This creates a similar result to a Panosphere projection.

### Reflection

Reflection maps the cubemap based on the reflection vectors. This is similar to using a fallback cubemap for Reflections & Specular.

## Color

<Property type="color" />

Tint color applied to the cubemap texture. This color is multiplied with the cubemap texture.

## Cubemap

<Property type="texture" texture="cubemap" />

Cubemap texture used. This must be in the cubemap format, which can be created from panoramic textures, or from 6 cube faces.

## Blending

<Property type="dropdown" options={['Replace', 'Multiply', 'Add']} />

Defines how the cubemap effect should be blended with the base color.

## Blend Alpha

<Property type="range" min="0" max="1" />

How much to blend the Alpha of the Cubemap.

## Brightness

<Property type="range" min="0" max="5" />

Intensity of the Cubemap overall.

## Emission Strength

<Property type="range" min="0" max="20" />

How much emission to apply to the cubemap.

## Smoothness

<Property type="range" min="0" max="1" />

How much smoothing to apply of the Cubemap.

## Normal to Use

<Property type="dropdown" options={['Pixel', 'Vertex']} />

Which normal to use if custom normals are not selected. `Pixel` normals are normals affected by normal maps, `Vertex` normals use only the base normals of the mesh. This is useful for applying the cubemap to a mesh that has been deformed by a normal map, while keeping the cubemap smooth.

## Masking

### Mask

<Property type="texture" texture="data" />

Mask that defines where to apply the cubemap effect. Black indicates where the cubemap should not be applied, and white indicates where it should be applied.

### Hide in Shadow

<Property type="range" min="0" max="1" />

How much to hide the cubemap effect in shadowed areas of the mesh.

### Global Mask

<Property type="dropdown" options={['Off', '1R', '1G', '1B', '1A', '2R', '2G', '2B', '2A', '3R', '3G', '3B', '3A', '4R', '4G', '4B', '4A']} />

Select which [Global Mask](/modifiers/global-masks.mdx) to use for the Cubemap mask.

## Color Adjust

### Color Space

<Property type="dropdown" options={['OKLab', 'HSV']} default="OKLab" />

Choice of Color Space to use for the Hue Shift. By default, it will be set to `OKLab`.

Learn about the difference of Color Spaces as documented here in [Color Adjust](/color-and-normals/color-adjust.mdx#oklab-vs-hsv).

### Select or Shift

<Property type="dropdown" options={['Hue Select', 'Hue Shift']} default="Hue Shift" />

This dropdown allows you to select how the Color Adjustment should behave when the Hue Shift is used. By default, this will be set to `Hue Shift`.

<details>
<summary><b>Select or Shift Options</b></summary>

- `Hue Select`: Directly applies the selected Hue as an override to the entire Cubemap.
- `Hue Shift`: Only tints the Cubemap based on the lerped value. This is the default behavior.

</details>

### Hue Shift Speed

<Property type="float" />

How much to constantly shift the Cubemap hue with time. A value of 1 will result in a full hue shift cycle every 20 seconds.

### Hue Shift

<Property type="range" min="0" max="1" default="0" />

How much to shift the Cubemap color around the hue circle.

This value is circular, and will have the same result at `0` and `1`.

### Brightness

<Property type="range" min="-1" max="2" default="0" />

Adjusts the brightness of the Cubemap. 

This increases or decreases brightness directly on top of the existing color, without regard for it's hue or tone.

### Contrast

<Property type="range" min="-1" max="10" default="1" />

Sets the contrast of rich colors on the Cubemap.

### Saturation

<Property type="range" min="-1" max="10" default="0" />

Adjusts the saturation of the Cubemap. 

A value of `-1` will make the Cubemap color fully de-saturate (grayscale). A value of `0` will not alter the color at all. A value greater than 0 will increase the saturation.

This is implemented as a lerp between the base color and a grayscale version of the base color.
