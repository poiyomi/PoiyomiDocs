The Details section provides options to apply additional textures (often tiled) to the base color and normals. When tiled, this feature can grant the user to bring out additional small details on the model without sacrificing quality.

This section contains more customization features for 2nd Normals in comparison to [Normal Map 2](/color-and-normals/normal-map-2.mdx).

## Detail Mask

<Property type="texture" texture="data" />

A texture that defines how and where to apply different detail textures.

| Channel | Mask |
|--|--|
| Red | Detail Texture |
| Green |  Detail Normal  |
| Blue | n/a |

## Detail Texture

### Tint

<Property type="color" default="#FFFFFF" />

A tint color that's blended multiplicative with the Detail Texture.

### Detail Texture

<Property type="texture" texture="color" />

Texture used to add detail to the base color. This texture is blended multiplicative with the base color.

### Intensity

<Property type="range" min="0" max="10" default="1" />

How much to blend the detail texture with the main texture.

### Brightness

<Property type="range" min="0" max="2" default="1" />

Multiplier for the detail texture's base brightness. Can be used to emphasize darker parts of a detail texture.

### Global Mask

<Property type="dropdown" options={['Off', '1R', '1G', '1B', '1A', '2R', '2G', '2B', '2A', '3R', '3G', '3B', '3A', '4R', '4G', '4B', '4A']} />

Select which [Global Mask](/modifiers/global-masks.mdx) to only affect the Detail Texture onto.

## Detail Normal

### Detail Normal

<Property type="texture" texture="normal" />

A normal map texture that's blended with the base normal map. 

#### Normal Intensity

<Property type="range" min="0" max="10" />

Intensity multiplier for the detail normal map. Expand the Detail Normal texture slot to see this property.

### Global Mask

<Property type="dropdown" options={['Off', '1R', '1G', '1B', '1A', '2R', '2G', '2B', '2A', '3R', '3G', '3B', '3A', '4R', '4G', '4B', '4A']} />

Select which [Global Mask](/modifiers/global-masks.mdx) to only affect the Detail Normal onto.
